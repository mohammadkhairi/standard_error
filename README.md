# Standard Error

## Purpose
The purpose of this package is to standard all of the error in the application

## Installation
``npm install https://github.com/mohammadkhairi/standard_error.git``

## How to import
`` const StandardError = require('standard-error') ``

## Parameters
* error_code
* message
* last_error
* context

### Error_code
The code which is used to determined the error thrown by the application.

### Message
The message which is used to explain the error thrown by the application

### Last_error
The error stack generated by the application. this is nullable

### Context
The context of the error. usually the context is the parameter sent

## How To Use
``throw new StandardError('ERROR_CODE_EXAMPLE', 'ERROR CODE MESSAGE', err, contextOfTheError)``
